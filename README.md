# Slidewood · 木块滑块解锁

一个纯单文件的木质滑块解谜游戏（Unblock Puzzle）。滑动木块，把红木块从右侧出口推出。

## 在线试玩

部署后访问 GitHub Pages 地址即可游玩（仓库 Settings → Pages → 选择 main 分支）。

## 特性

- 🧩 **24 个手工+算法精选关卡**，最优步数从 3 步平滑递增到 37 步
- 🪵 **拟真木材质感**:SVG 噪声木纹（横竖纹理方向区分）、四种真实木材主题（橡木/胡桃/樱桃/乌木）
- 🔊 **WebAudio 合成音效**：木头敲击、滑动摩擦、落子闷响、过关木琴音，零音频文件
- 👆 **丝滑拖拽**:1:1 跟手 + 松手吸附回弹，支持鼠标与触屏
- 💡 **内置 BFS 提示**：任意局面可给出最优解下一步
- ⭐ **星级评价与本地存档**（localStorage)
- 📱 **移动端适配**：响应式布局、防长按/双击干扰

## 技术

单个 `index.html` 包含全部 HTML/CSS/JS 与关卡数据，无任何外部依赖，可直接部署到任意静态托管。

## 本地运行

直接双击打开 `index.html`，或：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
